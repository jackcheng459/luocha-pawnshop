# Changelog

## v1.5.0

- 新增命主故事生成链路：结当离店进入当票页后异步生成一夜笔记。
- 新增故事只读页：`/story/{storyId}`。
- 新增命格卡与当票卡二维码故事入口。
- 新增临别金句库类型、随机取用逻辑和 fallback 金句。
- 新增金句管理页：`/admin/phrases`。
- 新增 Vercel KV/Upstash REST 存储抽象，未配置 KV 时走内存或本地 fallback。
- 新增金句和故事 JSON 导出接口。
- 新增 v1.5 相关维护文档。
- 修复二维码尺寸与对比度，改为高纠错率二维码。
- 接入“九两九钱，整整。客官身上不少不多，与众生同。”等世界观暗线台词。
- 新增节气/夜维度字段，并写入命格卡和命主故事记录。
- 新增玩家典当输入采集接口，作为待审核内容素材入库。
